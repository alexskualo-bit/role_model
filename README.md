# Role Center — HTML-прототип

Статическая версия интерактивного прототипа центра управления ролями. Откройте [index.html](index.html) в браузере; установка и локальный сервер не нужны. В файле уже находятся стили, интерфейс и данные для общей модели и ClubFirst.

Числовые примеры ClubFirst — **демонстрационные расчёты, не фактические показатели клуба**. Прототип хранит сделанные в браузере изменения локально; он не подключён к CRM, ПСВ или общей базе пользователей.

## Изменение прототипа

Исходный интерфейс и данные находятся в `src/`. После правок выполните:

```bash
npm install
npm run build
```

Команда пересоберёт автономный `index.html` в корне репозитория. Папка `.build/` — временный результат сборки и в Git не добавляется.

Для GitHub Pages можно выбрать публикацию из ветки `main`, папка `/ (root)`; стартовой страницей будет тот же `index.html`.
